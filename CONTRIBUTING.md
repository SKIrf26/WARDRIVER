# Contributing

Thanks for taking an interest. This is a small project at **Beta 1**, so the most useful help right now is **testing and bug reports**.

## Reporting a problem
Open an issue and pick **Bug report**. The form asks for what is needed:
- which release you used (shown on the boot screen) and how you installed it,
- what you did and what you expected,
- the lines from the Serial Monitor (115200 baud). For capture problems, include the `Transport ...` line printed when you pick a ride and the `Wardrive started` / `Wardrive stopped` lines.

## Suggesting a feature
Use **Feature request**. Say what you would like and how you would use it on a run.

## Code changes
Pull requests are welcome. Please keep each one small and focused, build it (see [docs/BUILDING.md](docs/BUILDING.md)) and describe how you tested it. [docs/CODE_MAP.md](docs/CODE_MAP.md) shows where each part of the firmware lives. The vehicle art, icons and fonts are generated: change the scripts in `tools/art/`, not the headers. By contributing you agree that your contribution is released under the same licence as the project (GPL v3).

## Responsible use
This project logs openly broadcast networks for mapping and fun. Features that join networks without permission, attack them, or aim to track individual people will not be accepted.
