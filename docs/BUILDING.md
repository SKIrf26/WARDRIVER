# Building from source

The firmware is one Arduino sketch: `src/SKIrf_WARDRIVER_C5_CYD/SKIrf_WARDRIVER_C5_CYD.ino`, with four header files beside it. The folder name must stay the same as the `.ino` name.

| File | What it is |
|---|---|
| `SKIrf_WARDRIVER_C5_CYD.ino` | The firmware |
| `SKIrf_C5_CYD_LGFX.h` | Display (ST7789) and touch (XPT2046) set-up for LovyanGFX |
| `SKIrf_Sprites.h` | Vehicle pixel art, generated by `tools/art/vehicles.py` |
| `SKIrf_Icons.h` | Interface icons, generated by `tools/art/icons.py` |
| `SKIrf_Fonts.h` | Anti-aliased fonts, generated by `tools/art/mkvlw.py` |
| `SKIrf_Web.h` | The web portal (page, fonts, logo), generated by `tools/web/make_web_assets.py` from `tools/web/portal.html` |

The three generated headers are not meant to be edited by hand. See [Regenerating the art](#regenerating-the-art).

## What you need

- Arduino IDE 2.x, or `arduino-cli`
- The **esp32** board package by Espressif Systems, version 3.3.x (this release was built with 3.3.12)
- These libraries, from the Library Manager:

| Library | Version used | By | Licence | For |
|---|---|---|---|---|
| LovyanGFX | 1.2.33 | lovyan03 | FreeBSD (BSD 2-clause) | Display, touch, sprites, smooth fonts |
| XPT2046_Touchscreen | 1.4 | Paul Stoffregen | MIT | Raw touch reads |
| TinyGPSPlus | 1.1.0 | Mikal Hart | LGPL 2.1+ | GPS (NMEA) parsing |
| ArduinoJson | 7.4.2 (6.x also works) | Benoit Blanchon | MIT | Settings files and WDGWars replies |

Wi-Fi, Bluetooth, the web server, TLS, SD and LittleFS come with the board package. Stock TFT_eSPI does **not** support the ESP32-C5, which is why this sketch uses LovyanGFX: no library set-up files need to be copied.

## Build in the Arduino IDE

1. Install the board package and the libraries above.
2. Open `src/SKIrf_WARDRIVER_C5_CYD/SKIrf_WARDRIVER_C5_CYD.ino`. The five files in that folder must stay together.
3. Choose **Tools** settings:
   - Board: "ESP32C5 Dev Module"
   - Flash Size: "8MB (64Mb)" (also right for 16 MB boards)
   - Partition Scheme: "8M with spiffs (3MB APP/1.5MB SPIFFS)"
   - PSRAM: "Enabled"
   - USB CDC On Boot: "Disabled" (the Serial Monitor then works on the left USB-C port)
4. Press **Upload**. The first build takes a few minutes. If the upload does not start, unplug the cable, HOLD the board's BOOT button, plug the cable in, release BOOT, and upload again.
5. Open **Tools > Serial Monitor** at 115200 baud to see the start-up messages (`=== WARDRIVER BOOT ===` ... `=== READY ===`).

The app is about 2.1 MB, so the default 1.3 MB app partition is too small: pick the partition scheme above.

## Build with arduino-cli

```
arduino-cli compile --fqbn espressif:esp32:esp32c5:FlashSize=8M,PartitionScheme=default_8MB,PSRAM=enabled --export-binaries src/SKIrf_WARDRIVER_C5_CYD
arduino-cli upload  --fqbn espressif:esp32:esp32c5:FlashSize=8M,PartitionScheme=default_8MB,PSRAM=enabled --port YOUR_PORT src/SKIrf_WARDRIVER_C5_CYD
```

The compiled files are written to `src/SKIrf_WARDRIVER_C5_CYD/build/espressif.esp32.esp32c5/`.

## Make the release image

`arduino-cli` and the Arduino IDE write a merged image padded with blank bytes to the full flash size, which would also wipe the log storage area when written. `tools/make_release_bin.py` cuts it to the part that matters and writes the checksum list:

```
python3 tools/make_release_bin.py src/SKIrf_WARDRIVER_C5_CYD/build/espressif.esp32.esp32c5 out
```

It writes `SKIrf_WARDRIVER_C5_CYD_Beta_1.bin` and `SHA256SUMS.txt` into `out/`, after checking the layout (bootloader at `0x2000`, partition table at `0x8000`, application at `0x10000`).

## Options at the top of the sketch

| Option | Default | What it does |
|---|---|---|
| `SKIRF_VERSION` | `"Beta 1"` | Release name on the boot screen |
| `SKIRF_APP_RELEASE` | `"0.1.0-beta.1"` | Release written into each WiGLE CSV header |
| `SKIRF_PANEL_BGR` | `1` | This board's panel swaps red and blue. Every colour goes through `C565()`, so if a different panel shows red as blue, set this to `0` |
| `SKIRF_WIFI_COUNTRY` | `"US"` | Wi-Fi country for scanning. `US` allows 5 GHz channels 149-165. Set your own two-letter code |

Pins are `#define`d just below (touch CS 1, SD CS 10, buzzer 26, backlight 25). The display bus is in `SKIrf_C5_CYD_LGFX.h`. GPS pins are chosen on the board (Settings > GPS pins).

## Regenerating the art

You only need this to change the vehicles, icons or fonts. The scripts need Python 3 and Pillow (`pip install pillow`).

```
python3 tools/art/vehicles.py src/SKIrf_WARDRIVER_C5_CYD/SKIrf_Sprites.h vehicles_preview.png
MDI_TTF=/path/to/materialdesignicons-webfont.ttf python3 tools/art/icons.py src/SKIrf_WARDRIVER_C5_CYD/SKIrf_Icons.h
python3 tools/art/mkvlw.py src/SKIrf_WARDRIVER_C5_CYD/SKIrf_Fonts.h \
  "VLW_XS SairaSemiCondensed-SemiBold.ttf 11 1 1.2" "VLW_S SairaSemiCondensed-SemiBold.ttf 13 1 1.0" \
  "VLW_M SairaSemiCondensed-SemiBold.ttf 16 1 1.0"  "VLW_L SairaSemiCondensed-SemiBold.ttf 22 1 1.2" \
  "VLW_XL SairaSemiCondensed-SemiBold.ttf 44 1 1.5" "VLW_DS SairaSemiCondensed-SemiBold.ttf 14 0 0.3" \
  "VLW_DK SairaSemiCondensed-SemiBold.ttf 20 0 0"
```

To change the web portal, edit `tools/web/portal.html` and run (needs Pillow, fontTools and brotli: `pip install pillow fonttools brotli`; point `SAIRA_DIR` at a folder with SairaSemiCondensed-Medium.ttf and -Bold.ttf):

```
SAIRA_DIR=/path/to/fonts python3 tools/web/make_web_assets.py
```

Each font argument is `NAME file.ttf size caps tracking`: `caps 1` draws every letter as a capital and fits the glyphs to the capital height so text centres optically. Saira Semi Condensed is available from Google Fonts (SIL OFL 1.1). The icons come from the Material Design Icons webfont 6.9.96 (`@mdi/font`).
