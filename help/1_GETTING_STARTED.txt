1. GETTING STARTED
==================

What the board is
-----------------
The NM-CYD-C5 is a small board with an ESP32-C5 chip, a 2.8 inch resistive touch screen (240 x 320), a microSD
card slot and USB-C ports. The ESP32-C5 has Wi-Fi on both 2.4 GHz and 5 GHz and Bluetooth LE. SKIrf Wardriver is
the software that runs on it.

Parts to add
------------
  GPS          Needed for logging. A module such as the ATGM336H (GPS + BeiDou) or any NMEA module at 9600 baud.
               By default the board reads the module's TX on IO4 (and its RX on IO5). On many boards IO4 receives
               nothing: if the GPS screen says NO DATA, wire the module's TX to IO8 and RX to IO9 and pick the
               8 / 9 preset in Settings > GPS pins. The board finds the module at 9600, 38400 or 115200 baud. With
               the RX wire connected it sets ATGM336H-style modules to the motion mode of your ride (not saved in
               the module). Flashing resets the GPS pins: set them again after every flash.
  microSD      Recommended. FAT32, 32 GB or smaller is safest. Fit it BEFORE you switch the board on.
               Settings > Storage tests it (TEST CARD) and chooses where logs go: CARD (the default with a card),
               AUTO (card, flash if the card fails) or FLASH (the board's own flash, about 1.5 MB). Your Wi-Fi and
               API keys are kept on the card and in the board.
  Buzzer       Optional. A small PASSIVE buzzer or piezo: + to IO26, - to GND. Without it the board is silent.
  Phone/laptop Optional. Used for the web portal: download logs, save your Wi-Fi and API keys.

Step by step
------------
 1. Put the software on the board: help/2_FLASHING.txt.
 2. The first start asks you to calibrate touch: TOUCH CAL, "Tap the four corners". Tap the marker that appears
    in each corner in turn (a stylus or fingernail tip works best). The board says "Cal saved" and restarts.
 3. The boot screen shows the SKIrf logo with BETA 1 under it.
 4. Next comes the WEB PORTAL screen for 60 seconds, longer while you use it (see "The web portal" below). Tap SKIP
    if you do not need it.
 5. You land on HOME: a radar, the START WARDRIVE button, and GPS, LOGS and SETTINGS.
 6. Open GPS and wait until FIX says LOCKED or 3D LOCK (outdoors, clear sky; the first fix can take a few minutes).
 7. Tap START WARDRIVE, pick your ride (CAR, MOTO or WALK/BIKE). The wardrive screen opens; tap START.
    The big number is how many unique networks and devices you have caught this run.
 8. To finish, tap STOP: it turns amber and says TAP TO STOP. Tap it again within 3 seconds. The RUN REPORT appears.

The web portal
--------------
For 60 seconds after each start (and as long as a page has it open) the board makes its own open Wi-Fi hotspot
called SKIrf_WARDRIVER. Join it with a phone or laptop and open http://192.168.4.1 (not https). The page has three
tabs:
  Logs     your runs, newest first: download one, select several to upload / download as .zip / delete
  Upload   send selected or all logs to WiGLE, WDGWars or both (the board then leaves the hotspot, joins your home
           Wi-Fi, shows the progress on its screen and turns Wi-Fi off again; open the portal later to see results)
  Setup    home Wi-Fi, WiGLE API name and token, WDGWars API key, the run journal, delete all logs
Open it again any time from Settings > Web portal. When the board is on your home Wi-Fi (Settings > Wi-Fi > CONNECT),
the same page is at the address shown on the Wi-Fi screen.

Uploading your runs
-------------------
 1. Save your home Wi-Fi (Settings > Wi-Fi > NETWORKS, or in the web portal) and your API keys (web portal).
 2. Open LOGS, tap the runs to select them (or ALL), then tap WIGLE or WDGW. The board joins your home Wi-Fi and
    uploads each file.
