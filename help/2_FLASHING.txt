2. FLASHING THE .bin FILE
=========================

You need: the file SKIrf_WARDRIVER_C5_CYD_Beta_1.bin (and SHA256SUMS.txt) from the project's Releases page, the
board, a USB-C DATA cable, and a computer with Python 3.

 1. Check the download (optional but recommended)
      Windows PowerShell:   Get-FileHash .\SKIrf_WARDRIVER_C5_CYD_Beta_1.bin -Algorithm SHA256
      macOS / Linux:        shasum -a 256 -c SHA256SUMS.txt
    The value must match the line for that file in SHA256SUMS.txt.

 2. Install the flashing tool (once)
      pip install esptool
    (On Windows, if "pip" is not found, use:  py -m pip install esptool )

 3. Plug the board into the computer with the USB-C cable. Use the LEFT USB-C port (the USB-UART port): the
    computer can reset the chip into flashing mode by itself there.
    Find its port:
      Windows   Device Manager > Ports (COM & LPT): for example COM5
      macOS     /dev/cu.usbserial... or /dev/cu.wchusbserial...   (list with:  ls /dev/cu.*)
      Linux     /dev/ttyUSB0 or /dev/ttyACM0   (you may need to be in the "dialout" group)

 4. Write the file (replace YOUR_PORT):
      esptool --chip esp32c5 --port YOUR_PORT --baud 460800 write-flash 0x0 SKIrf_WARDRIVER_C5_CYD_Beta_1.bin
    ("write_flash" with an underscore is the older spelling and also works on older esptool versions.)

 5. When it says "Hash of data verified" and "Hard resetting", the board restarts by itself.
    Calibrate the touch screen (tap the marker in each corner). The boot screen shows BETA 1 under the logo.

If the computer cannot connect to the board
-------------------------------------------
  * Use a USB-C DATA cable, not a charge-only one. Try another USB port on the computer.
  * Put the chip in download mode: unplug the cable, HOLD the board's BOOT button, plug the cable in, release BOOT,
    and run the command again.
  * The MIDDLE USB-C port is the chip's own USB port. It also works, but the chip must be put into download mode by
    hand: hold BOOT, tap RESET, release BOOT, then pick the port that appears and run the command again. After the
    write finishes, press RESET once to start the board.
  * Slow or unreliable connection? Lower the speed:  --baud 115200

What flashing changes
---------------------
Writing this file replaces the software and RESETS THE SETTINGS SAVED IN THE BOARD: touch calibration, theme,
brightness, orientation, GPS pins, Pro mode settings and your records (best run, lifetime total). Files on the
microSD card are not touched: your logs and the saved Wi-Fi and API keys stay. (Without a card, logs and keys kept
in the board's flash may be lost when you flash.)

Updating later
--------------
Flash the newer .bin the same way.
